# Точечные примеры SDK

Эти автономные проекты показывают по одной операции Trade API за раз. Их
закоммиченные манифесты и lock-файлы используют опубликованные пакеты SDK, как
это делает приложение вне репозитория.

| Язык | Пакет | Примеры |
| --- | --- | --- |
| [Node.js](node/) | `@finam/trade-api@2.19.1` из npm | аутентификация, котировки, лимитная заявка |
| [Python](python/) | `finam-sdk==2.19.0` из PyPI | аутентификация, асинхронные котировки, лимитная заявка |

## Настройка секрета

Один игнорируемый git файл в корне репозитория хранит `TRADE_API_SECRET` и
остальные общие настройки, и каждый рецепт `just` загружает его:

```sh
# Из корня репозитория
cp .env.example .env
# Отредактируйте .env, затем:
just env-status
just run-sdk-python auth_and_account.py
just run-sdk-node auth
```

Сами примеры никогда не читают `.env`. Чтобы запустить пример напрямую из его
каталога, сначала экспортируйте `TRADE_API_SECRET` в оболочке.

Начните с ограниченного примера аутентификации для своего языка. Примеры с
заявками защищены отдельно, потому что отправляют настоящие заявки.

## Локальный SDK для контрибьюторов

По умолчанию используются опубликованные пакеты. Контрибьюторы могут временно
заменить установленные пакеты на SDK из текущего checkout:

```sh
just examples-use-local
just examples-status
```

`just examples-use-published` возвращает все зафиксированные опубликованные
пакеты. С экспортированным секретом `just smoke-examples-local` или
`just smoke-examples-published` запускает все ограниченные проверки только на
чтение в выбранном режиме.
