# Примеры Node.js SDK

Это автономные примеры приложений для опубликованного пакета
`@finam/trade-api@2.19.1`. Они не импортируют исходники SDK и protobuf-файлы из
этого репозитория.

## Установка и аутентификация

Нужен Node.js 20 или новее. Из корня репозитория:

```sh
cd examples/sdk/node
npm ci
TRADE_API_SECRET=... npm run smoke
```

Ограниченный smoke-тест аутентифицируется, печатает видимые ID счетов и
запрашивает первый счёт, если он есть. Он никогда не выставляет заявку.

Чтобы держать секрет в одном месте, а не в каждой команде, заполните корневой
`.env` (см. [Настройку секрета](../README.md#настройка-секрета)) и запустите
тот же пример через `just`, который его загружает:

```sh
just run-sdk-node auth
```

## Поток котировок

Этот пример только читает и работает до Ctrl-C:

```sh
TRADE_API_SECRET=... \
TRADE_API_SYMBOL=SBER@MISX \
npm run quotes
```

## Выставить настоящую лимитную заявку

> **Внимание:** пример отправляет настоящую заявку, которая может исполниться
> сразу. Он не пытается её отменить. Используйте выделенный счёт и проверьте
> каждое значение.

```sh
TRADE_API_SECRET=... \
TRADE_API_SYMBOL=SBER@MISX \
TRADE_API_QUANTITY=1 \
TRADE_API_LIMIT_PRICE=REPLACE_WITH_LIMIT_PRICE \
TRADE_API_EXECUTE=1 \
npm run order
```

У примера с заявкой намеренно нет цены по умолчанию.

## Контрибьюторам: локальный SDK

Закоммиченная зависимость и lock-файл всегда указывают на опубликованный пакет.
Из корня репозитория можно подключить SDK из текущего checkout:

```sh
just examples-use-local-node
just examples-status
```

Локальные примеры Node.js используют собранный каталог `dist` SDK. Для
итеративной отладки запустите `just watch-node-sdk` во втором терминале.
Вернуть опубликованный пакет детерминированно:

```sh
just examples-use-published-node
```
