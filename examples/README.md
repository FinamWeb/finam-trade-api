# Примеры Finam Trade API

Начните с полной стратегии, если хотите увидеть, как аутентификация,
исторические рыночные данные, потоки, расчёт сигнала, обнаружение счёта и
защищённое выставление заявок работают вместе.

## Самый быстрый безопасный пример

Проверка истории SMA-стратегии делает только запросы на чтение и завершается
после одного результата. Из корня репозитория:

```sh
cd examples/strategies/sma_crossover/python
uv sync --locked
TRADE_API_SECRET=... uv run python main.py --symbol SBER@MISX --check
```

Пользователи Node.js могут запустить эквивалентную реализацию:

```sh
cd examples/strategies/sma_crossover/node
npm ci
TRADE_API_SECRET=... npm start -- --symbol SBER@MISX --check
```

Та же команда работает в `examples/strategies/macd_zero_cross/` и
`examples/strategies/rsi_threshold/` — двух других стратегиях этого
репозитория.

## Один файл окружения для всех примеров

Вместо того чтобы повторять `TRADE_API_SECRET=...` в каждой команде,
скопируйте единственный `.env.example` из корня репозитория в `.env`, заполните
его один раз и запускайте любой пример через `just`, который загружает этот
файл:

```sh
cp .env.example .env
# Отредактируйте .env, затем:
just env-status
just run-strategy-python sma_crossover --check
just run-strategy-node sma_crossover --check
just run-sdk-python auth_and_account.py
just run-sdk-node auth
```

`.env` исключён из git, а переменные, уже экспортированные в оболочке, имеют
приоритет над ним. Сами программы-примеры никогда не читают файл, поэтому каждый
каталог остаётся запускаемым после копирования из репозитория. Что делает каждое
правило и какие соглашения о безопасности общие, описано в
[Торговых стратегиях](strategies/).

## Точечные примеры SDK

Используйте небольшие автономные проекты, когда нужна одна операция за раз:

- [Примеры Python SDK](sdk/python/) — аутентификация и обнаружение счёта,
  асинхронные котировки и пример лимитной заявки.
- [Примеры Node.js SDK](sdk/node/) — аутентификация и обнаружение счёта,
  котировки и пример лимитной заявки.

Каждый проект фиксирует и устанавливает опубликованный SDK ровно так, как это
делало бы отдельное приложение-потребитель. Контрибьюторы могут временно
заменить эти установки на SDK из текущего checkout через корневые команды
`just`, описанные в [Разработке репозитория](../README.md#разработка-репозитория).

Примеры с заявками отправляют настоящие запросы. Прочитайте их предупреждения и
используйте выделенный тестовый счёт; рекомендуемый первый запуск — проверка
истории стратегии выше.
