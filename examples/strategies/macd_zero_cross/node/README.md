# Пересечение нуля MACD 12/26/9 — Node.js

Реализация [стратегии пересечения нуля MACD](../README.md) на TypeScript с
использованием опубликованного пакета `@finam/trade-api@2.19.1`.

## Быстрый старт

Нужен Node.js 20 или новее. Из корня репозитория:

```sh
cd examples/strategies/macd_zero_cross/node
npm ci
TRADE_API_SECRET=... npm start -- --symbol SBER@MISX --check
```

Режим проверки аутентифицируется, загружает исторические свечи, считает
последние подтверждённые значения MACD, печатает один результат и завершается.
Он не читает счёт, не открывает поток и не выставляет заявку.

```text
History check passed: close=... macd=... macd_signal=... histogram=... signal=...
```

Если аутентификация не проходит, убедитесь, что секрет активен и имеет доступ к
рыночным данным. Если свечи не возвращаются, проверьте инструмент `ticker@mic` и
его рынок. Правилу нужно 35 свечей на прогрев, поэтому длинный таймфрейм может
сообщить о нехватке свечей; `--timeframe M5` по умолчанию даёт их с запасом.

## Потоковый dry-run

По умолчанию dry-run. Он читает настоящие исторические и потоковые рыночные
данные и логирует сигналы, но никогда не читает счёт и не выставляет заявку.
Остановите его через Ctrl-C.

```sh
TRADE_API_SECRET=... \
npm start -- --symbol SBER@MISX --timeframe M5 --quantity 1
```

Флаги можно заменить переменными окружения из общей
[таблицы настроек](../README.md#настройки). Ни Node.js, ни этот пример сами не
читают корневой `.env`; `just run-strategy-node macd_zero_cross` загружает его
за вас. Все флаги: `npm start -- --help`.

## Включить настоящее исполнение

> **Внимание:** `--execute` может выставлять настоящие рыночные заявки.
> Используйте выделенный счёт, разберитесь в
> [ограничениях защитных проверок](../README.md#защитные-проверки) и сначала
> проверьте режимы check и dry-run.

```sh
TRADE_API_SECRET=... \
npm start -- --symbol SBER@MISX --quantity 1 --execute
```

На старте стратегия обнаруживает ID счетов через `AuthService.TokenDetails` и
отказывается исполнять заявки, если токену доступно не ровно один счёт. Она
также стартует вне позиции, поэтому никогда не продаёт позицию, которую не
открывала.

## Локальные тесты

Секрет и доступ к сети не нужны:

```sh
npm run check
```

Команда запускает Biome, TypeScript и точечные unit-тесты. Используйте
`npm run format` только когда действительно хотите изменить форматирование.

## Чтение реализации

1. [`strategy.ts`](strategy.ts) — чистый расчёт MACD и правило пересечения нуля.
2. [`config.ts`](config.ts) — флаги и настройки из окружения.
3. [`runner.ts`](runner.ts) — закрытые свечи, отслеживание позиции, защищённые
   заявки.
4. [`main.ts`](main.ts) — исполняемая точка входа.
5. [`tests/macd-zero-cross.test.ts`](tests/macd-zero-cross.test.ts) — примеры
   ожидаемого поведения.

`evaluate` принимает длины окон аргументами, поэтому тот же модуль покрывает и
другие настройки MACD. Каталог самодостаточен и не импортирует исходники SDK и
protobuf-файлы из этого репозитория. Точная фиксация версии пакета также делает
его потребительским тестом опубликованного релиза.

Контрибьюторы репозитория могут временно подключить SDK из этого checkout, не
меняя `package.json` и `package-lock.json`. Из корня репозитория:

```sh
just examples-use-local-node
just examples-status
```

Запустите `just watch-node-sdk` во втором терминале, чтобы пересобирать
подключённый SDK при изменениях. Вернуть опубликованную зависимость:
`just examples-use-published-node`.
