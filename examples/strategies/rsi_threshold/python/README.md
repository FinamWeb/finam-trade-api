# Пороги RSI 14 — Python

Реализация [стратегии порогов RSI](../README.md) на Python с использованием
опубликованного SDK Finam (`finam-sdk==2.19.0`, импортируется как
`finam_trade_api`).

## Быстрый старт

Нужны Python 3.10 или новее и [uv](https://docs.astral.sh/uv/). Из корня
репозитория:

```sh
cd examples/strategies/rsi_threshold/python
uv sync --locked
TRADE_API_SECRET=... uv run python main.py --symbol SBER@MISX --check
```

Режим проверки аутентифицируется, загружает исторические свечи, считает
последний подтверждённый RSI, печатает один результат и завершается. Он не
читает счёт, не открывает поток и не выставляет заявку.

```text
History check passed: close=... rsi=... average_gain=... average_loss=... signal=...
```

Значение `rsi` лежит на шкале 0..1, поэтому `0.2` и `0.8` — это уровни, которые
график подписал бы как 20 и 80. См. [Шкалу](../README.md#шкала-02-и-08-а-не-20-и-80).

Если аутентификация не проходит, убедитесь, что секрет активен и имеет доступ к
рыночным данным. Если свечи не возвращаются, проверьте инструмент `ticker@mic` и
его рынок. Правилу нужно 16 свечей на прогрев, поэтому длинный таймфрейм может
сообщить о нехватке свечей; `--timeframe M5` по умолчанию даёт их с запасом.

`uv sync` создаёт локальное виртуальное окружение, но не активирует его.
Сохраняйте префикс `uv run` в командах ниже, если не активируете `.venv` сами.

## Потоковый dry-run

По умолчанию dry-run. Он читает настоящие исторические и потоковые рыночные
данные и логирует сигналы, но никогда не читает счёт и не выставляет заявку.
Остановите его через Ctrl-C.

```sh
TRADE_API_SECRET=... \
uv run python main.py \
  --symbol SBER@MISX \
  --timeframe M5 \
  --quantity 1
```

Флаги можно заменить переменными окружения из общей
[таблицы настроек](../README.md#настройки). Python сам не читает корневой
`.env`; `just run-strategy-python rsi_threshold` загружает его за вас. Все
флаги: `uv run python main.py --help`.

## Включить настоящее исполнение

> **Внимание:** `--execute` может выставлять настоящие рыночные заявки.
> Используйте выделенный счёт, разберитесь в
> [ограничениях защитных проверок](../README.md#защитные-проверки) и сначала
> проверьте режимы check и dry-run.

```sh
TRADE_API_SECRET=... \
uv run python main.py --symbol SBER@MISX --quantity 1 --execute
```

На старте стратегия обнаруживает ID счетов через `AuthService.TokenDetails` и
отказывается исполнять заявки, если токену доступно не ровно один счёт. Она
также стартует вне позиции, поэтому никогда не продаёт позицию, которую не
открывала.

## Локальные тесты

Секрет и доступ к сети не нужны:

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy .
uv run pytest
```

## Чтение реализации

1. [`strategy.py`](strategy.py) — чистый расчёт RSI и правило порогов.
2. [`config.py`](config.py) — флаги и настройки из окружения.
3. [`runner.py`](runner.py) — закрытые свечи, отслеживание позиции, защищённые
   заявки.
4. [`main.py`](main.py) — исполняемая точка входа.
5. [`tests/test_rsi_threshold.py`](tests/test_rsi_threshold.py) — примеры
   ожидаемого поведения.

Расчёт не зависит от SDK, и его можно переиспользовать или тестировать без
учётных данных, сети и protobuf-сообщений. `evaluate` принимает период и оба
уровня аргументами, поэтому тот же модуль покрывает и другие настройки RSI.

Поскольку оба правила — уровни, а не пересечения, `evaluate` нужно состояние
позиции вызывающего кода, чтобы не повторять сигнал на каждой свече, остающейся
за уровнем. Этим флагом владеет `runner.py`; прочитайте
[Как отслеживается позиция](../README.md#как-отслеживается-позиция), прежде чем
переиспользовать `strategy.py` в собственном цикле.

Контрибьюторы репозитория могут временно установить SDK из этого checkout в
editable-режиме, не меняя `pyproject.toml` и `uv.lock`. Из корня репозитория:

```sh
just examples-use-local-python
just examples-status
```

Пока действует переопределение, используйте корневую smoke-команду или
`uv run --no-sync`. Вернуть опубликованный wheel:
`just examples-use-published-python`.

## Граница опубликованного SDK

Каталог самодостаточен, и его можно скопировать из репозитория. Для работы с
Trade API он импортирует только публичные модули `finam_trade_api`. Он не
импортирует ничего из `sdk/python`, сгенерированных модулей в
`finam_trade_api.proto` и «сырого» каталога `proto/` репозитория. Lock-файл
фиксирует wheel из PyPI и его SHA-256, а CI потребителя проверяет, что импорты
разрешаются из этого установленного дистрибутива.
